# DESIGN §35 — 2026-10-21 本地扩展同盟

Part of [DESIGN.md](../DESIGN.md) (the index; this is a local change note).

玩家决定加入独立的 5–8 人同盟模式，允许 AI 补位，满五人可开始。牌堆按席位数扩充，领袖生命随开战时存活人数扩大；联防最多三人并延长时限，新增无伤害阻挡的防卡死规则。战场第三段从当回合地图扩展，普通敌人的数值和禁选规则不变。当前规则见 [extended-coop.md](../design/extended-coop.md)。

后续已加入机械师「技术传承」。玩家又提供森蚺「机械援助」的策略头像和「双眼皮」技能 GIF：本局有一人选择森蚺后，所有玩家场地出现装置；基础攻击改为 1000 点法术伤害、最多两次 15% 衰减弹射，优先领袖，否则最低当前生命值；攻击速度和脆弱按各自阵地主人已激活盟约总层数超出 50 的部分计算。原四人模式及其装置效果不变。实测技能 GIF 与装置位置错位，按玩家决定撤去 GIF，保留灰色静态装置在地图原定格发射，完整射程为 3×5 格；之前的模拟装置被战斗区域边界挤到相邻格，现已改为原定格。策略头像存于忽略的本地素材目录，代码仓库不包含游戏美术文件。
