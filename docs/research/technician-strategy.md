# 机械师「技术传承」规则记录

这份记录补充 [大型同盟规则](../design/extended-coop.md)，仅适用于 5–8 人房间。

机械师开局生命值为 28，仅在 5–8 人大型模拟中可选。森蚺策略已按 [大型同盟规则](../design/extended-coop.md) 接入，开局生命值为 33。

该策略参考 Pith：开局获得一名一阶「盟约·重装干员」。其职业为驭法铁卫，所属盟约为坚守、奥术、助力。与「盟约·辅助干员」一样，它不列入普通盟约干员列表，也不能通过拟态物质、寻呼模块、简易通讯器等装备获得；可以通过博士投影进阶。

| 属性 | 普通 | 进阶 |
| --- | ---: | ---: |
| 生命值 | 2010 | 2702 |
| 攻击力 | 416 | 519 |
| 防御力 | 390 | 496 |
| 法术抗性 | 15 | 15 |

攻击间隔 1.6 秒，阻挡数 3，部署费用 21，再部署时间 70 秒。普通攻击只攻击一个目标，未开技能时造成物理伤害，开技能后造成法术伤害。进阶后解锁同驭法铁卫分支的模组：开技能时普通攻击改为法术伤害；攻击和受到攻击时，额外对目标造成攻击力 10% 的法术伤害。额外伤害仅在伤害属于普通攻击或普通攻击附带伤害、来源是本干员、并非本模组特性伤害时触发；对敌方反弹伤害只计算法术普通伤害。

天赋：自身法术抗性 +10；周围八格友方单位法术抗性 +5。

特质：坚守、奥术、助力层数先合计，每满 5 层本干员防御力 +1%；进阶后 +2%。

技能：开启期间获得庇护，并同时攻击所有被自身阻挡的敌人。普通形态获得 12% 庇护，初动 15、消耗 38、持续 25 秒；进阶形态获得 18% 庇护，初动 17、消耗 34、持续 25 秒。

立绘和动作素材使用「预备干员-重装」（泥岩未持有时使用的重装干员）。资源由现有素材包提供。数据生成后运行 `node tools/inject-technician-data.mjs` 可重新加入该本地策略。
