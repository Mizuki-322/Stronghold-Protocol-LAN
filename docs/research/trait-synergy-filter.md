# 特质联动速查（v0.3.1）

依据本版本 `data/chess.json` 的可见干员及 `data/garrisons.json` 的 `eventType` 整理。普通与精锐形态算同一名干员；甄选、自选及隐藏干员暂不计入。名单表示具有对应触发时机的特质，实际联动仍需满足站位、形态和特质本身的条件。

| 发起干员 | 联动方式 | 可筛选干员 |
| --- | --- | ---: |
| 铃兰 | 进入休整期时，再次触发前方干员的「获得时」效果；普通前一格，精锐前两格 | 22 |
| 白面鸮 | 复制前方一格干员的「进入休整期时」特质 | 10 |
| 塞雷娅 | 复制前方一格干员的「休整期结束时」特质 | 23 |
| 魔王（特蕾西娅） | 放大身前一格干员在战斗中因特质获得的盟约层数；另列可赋予队友叠层特质的干员 | 28（直接叠层 24、赋予叠层 4） |

**白面鸮 × 进入休整期时（10）**：赫默、蒂比、空弦、凯瑟琳、歌蕾蒂娅、缄默德克萨斯、铃兰、寒檀、余、佩佩。

**塞雷娅 × 休整期结束时（23）**：刺玫、波登可、雷蛇、小满、调香师、折桠、断崖、琳琅诗怀雅、薄绿、蛇屠箱、伊内丝、阿罗玛、莱恩哈特、号角、夕、引星棘刺、山、安洁莉娜、寒檀、妮芙、维娜·维多利亚、流明、溯光星源。

筛选只看目标干员自身特质的 `eventType`，不会因为说明中提到某个时机而误收录。例如铃兰说明中提及「获得时」，但她自身是「进入休整期时」特质。局内名单仍显示本局禁用干员，并用红叉标记；可用人数只计算未禁用者。

局内干员详情的特质下可打开以上四类联动名单。局内「本局信息」还能搜索并同时追踪多名干员；干员详情提供快捷开关，商店或奖励出现普通／精锐形态时会标记卡牌并提示。追踪只在当前一局有效。

独立查询页位于 `/synergy/`，按全部 8 种核心盟约、15 种附加盟约和六类特质机制筛选可见常规干员。六类依次是「获得时」22 名、「进入休整期时」11 名、「休整期结束时」24 名、「战斗中」29 名（自身叠层、授予队友叠层及魔王本人）、「战斗中增益」21 名，以及「其他」7 名。前面三类使用特质的 `eventType`，后面三类再按战斗效果键和未覆盖的时机细分；「其他」包含风丸、4 名售出时干员、刷新时的拉普兰德和购买价格特质的至简。普通和精锐形态取并集匹配，详情分别展示两种形态的特质。不同筛选组取交集；同组多选可切换「任一」或「全部」。

## 后续候选：战斗中叠层与条件触发

全部 51 名被归为战斗中特质的干员、魔王叠层关系及研究中的五组分类见 [战斗中特质与魔王叠层清单](battle-trait-theresa.md)。查询页将其中前三组放在「战斗中」，读取层数收益与其他明确的战斗增益放在「战斗中增益」，风丸的合成规则放在「其他」。

以下是供讨论的进一步联动笔记。魔王的直接叠层及赋予叠层候选已加入局内联动名单；后面的跨机制条件关系尚未加入快速筛选。依据同一版本的 `data/chess.json`、`data/garrisons.json` 和 `server/sim/content/garrisons/battle.js`。表中只列可见、非甄选、非自选、非隐藏干员；普通与精锐形态合并计数。名单表示具有相应的特质机制，不表示任何站位或阵容都能触发。

### 魔王：放大身前干员在战斗中由特质获得的层数

魔王的 `garrison_59_a/b` 在前方一格干员以**自己的特质**获得盟约层数时，分别使该次获得量额外 `+1/+2`。模拟器只处理原因标记为 `garrison` 的战斗内叠层；商店、休整期、盟约自身效果及其他原因产生的叠层不触发。魔王和触发者要属于同一玩家、在正确站位，相关盟约要已激活，且触发者须满足其特质条件及每场战斗上限。`魔王`自身不在下列候选中。

| 叠层触发条件 | 自带这种战斗特质的干员 |
| --- | --- |
| 开启技能 | 莎草、菲莱、百炼嘉维尔、塑心、纯烬艾雅法拉 |
| 击倒目标 | 送葬人、休谟斯、斯卡蒂、海霓、伺夜、风笛、荒芜拉普兰德 |
| 被击倒或替身切换 | 幽灵鲨、砾、归溟幽灵鲨 |
| 消耗弹药 | 莫斯提马、圣约送葬人、蕾缪安 |
| 范围内敌人进入冻结 | 初雪、银灰 |
| 部署 | 砾、瑕光、史尔特尔、锏 |
| 范围内目标进入沉睡或晕眩 | 缇缇 |

合计 **24 名不同干员**；砾在「被击倒」和「部署」两组重复出现。这是按普通、精锐形态所带特质的并集列出的候选名单；例如荒芜拉普兰德的这项特质出现在精锐形态。叠层可能同时涉及多个盟约，魔王按每次实际获得层数的盟约分别追加，不能把表中人数理解成固定强度排名。

### 把叠层特质赋予别人

这些关系不是单纯依靠目标自身的特质，筛选时可能需要额外检查形态、成员关系和站位：

| 发起干员 | 被赋予的战斗特质 | 潜在联动 |
| --- | --- | --- |
| 华法琳 | 身前一格干员开启技能，为其已激活的自身所属盟约叠层 | 技能可频繁开启的干员；受赠者若同时站在魔王身前，可再被魔王放大 |
| 寒芒克洛丝 | 身前一格干员开启技能，为已激活的「精准」叠层 | 技能频率、精准激活与站位；也可能接魔王 |
| 远牙 | 同一行最右侧干员部署，为已激活的「卡西米尔」「精准」叠层；代码也处理该受赠特质的替身切换 | 可反复部署或切换替身的干员；也可能接魔王 |
| 凛御银灰 | 身前一格「谢拉格」干员在范围内敌人进入冻结时，概率叠「谢拉格」层数 | 谢拉格干员与制造冻结的角色；也可能接魔王 |
| 精锐荒芜拉普兰德 | 所有「叙拉古」干员击倒敌人时叠「叙拉古」层数 | 击杀者与叙拉古成员；也可能接魔王 |

`ADD_BOND` 特质在开战前按站位授予目标，后续叠层仍由**受赠干员**触发，因此理论上符合魔王的来源判定。这里暂记为可验证的组合，不把所有受赠干员直接列入魔王的 24 人名单。耀骑士临光也会赋予身前干员特质，但该特质**读取**「卡西米尔」层数来提高属性，不主动增加层数，应归入下文的另一类。

### 其他值得做成关联索引的机制

| 关系 | 数据中可见的例子 | 仍需确认的边界 |
| --- | --- | --- |
| 消耗弹药 → 叠层 | 莫斯提马统计周围四格干员的弹药消耗，叠「拉特兰」；圣约送葬人、蕾缪安自己也有弹药消耗叠层特质。隐现、信仰搅拌机、烛煌、新约能天使等也有弹药技能 | 必须实际消耗弹药且满足距离；信仰搅拌机的「补弹」是间接帮助，不等于直接触发莫斯提马 |
| 进入冻结 → 叠层 | 初雪、银灰的特质，以及凛御银灰赋予的特质，均读取范围内敌人进入冻结；雪猎、耶拉、灵知、凛御银灰、寒檀等技能或天赋可施加寒冷 | 两次寒冷是否真的使目标**新进入冻结**，还受目标免疫、持续时间、范围等影响；仅有「寒冷」文字不能算成功触发 |
| 进入沉睡或晕眩 → 叠层 | 缇缇的特质；小满、缇缇能施加沉睡；德克萨斯、古米、雷蛇、幽灵鲨、寒芒克洛丝等可使目标或自己晕眩 | 须是范围内目标**新进入**状态，重复刷新不算；具体效果取决于技能、形态和战斗场面 |
| 层数来源 → 层数收益 | 耀骑士临光赋予的特质按「卡西米尔」层数增益；其他干员的特质也有「每叠加若干层……」 | 需要把「产生层数」与「读取哪种盟约层数」分开建关系，避免把同盟约全部成员当作直接搭档 |
| 休整期站位 | 空弦、断崖、引星棘刺等特质对前后格干员叠层或生效；白面鸮、塞雷娅可复制对应时机的特质 | 与现有按时机筛选交叉，但站位、复制顺序和本局可用情况仍需核对 |

后续可先决定「快速筛选」只收录机制上直接匹配的对象，还是也展示需要一定操作与站位才成立的配法，并在界面区分两者。不要仅靠文本含有「战斗中」或相同盟约就建立关联。
