# 战斗中特质与魔王叠层清单（v0.3.1）

依据本项目 `data/chess.json`、`data/garrisons.json` 和 `server/sim/content/garrisons/battle.js` 整理。范围是 **51 名**可见、非甄选、非自选、非隐藏的普通干员；普通与精锐形态合并为一名，任一形态有 `IN_BATTLE` 特质就列入。下面的效果是便于检索的提要，具体数值与条件以查询页打开的对应形态特质说明为准。按照能否和魔王（特蕾西娅）战斗叠层配合排列。

## 判定规则

魔王的 `garrison_59_a/b` 只会在**同一玩家、身前一格干员因其战斗特质获得盟约层数**时追加层数。服务器模拟器只接受 `reason: 'garrison'` 的战斗叠层；该盟约还要已激活，触发者须满足技能、击杀、状态、站位及每场上限等自身条件。魔王普通形态每次 `+1`，精锐形态每次 `+2`。仅有“战斗中”标签、使用弹药、施加状态、读取已有层数，均不足以单独触发魔王。

下列五组互不重复，合计 **24 + 4 + 1 + 21 + 1 = 51 名**。前三组放在前面供组队查询；其中“赋予队友”组需要让**受赠者**站到魔王身前。第④组「战斗中增益」包含原有的 16 名读取层数者及 5 名具有其他明确战斗增益者；风丸的合成规则暂留第⑤组。

## ② 赋予队友叠层特质：4 名

这四名干员自身不直接获得战斗层数，先按站位或盟约条件把特质赋给队友。队友触发被赋予的特质时，模拟器把队友作为叠层来源，因此队友若站在魔王身前，理论上可被魔王追加。具体阵容需满足两次站位关系与相关盟约激活条件。

| 干员 | 赋予的效果 |
| --- | --- |
| 寒芒克洛丝 | 身前一格干员开启技能时叠精准 |
| 远牙 | 同一行最右侧干员部署时叠卡西米尔、精准；该受赠特质也处理替身切换 |
| 华法琳 | 身前一格干员开启技能时叠其自身所属且已激活的盟约 |
| 凛御银灰 | 身前一格谢拉格干员见范围内敌人新进入冻结时，概率叠谢拉格 |

精锐荒芜拉普兰德也会**赋予**击杀叠层特质，但她自身就有直接叠层特质，因此已放在第①组，没有在此重复计数。技能、冻结或部署等事件仍受各受赠特质的上限与条件限制。
